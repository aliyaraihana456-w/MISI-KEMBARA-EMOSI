# Dunia Bandingan Semacam: Kembara Misi Emosi

Pembinaan semula laman pembelajaran untuk GitHub Pages.

## Kandungan
- `index.html`: halaman utama, CSS, JavaScript dan aktiviti interaktif.
- `assets/peta-kembara.png`: grafik peta zig-zag.
- Butang hotspot pada peta untuk Stesen Gembira, Sedih, Marah, Loya dan Pusat Memori.
- Butang stesen alternatif di bawah peta untuk aksesibiliti dan skrin kecil.

## Terbitkan
1. Ekstrak ZIP.
2. Muat naik `index.html`, `README.md` dan folder `assets` ke root repositori GitHub.
3. Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

Ini ialah pembinaan semula berdasarkan keperluan pengguna, bukan salinan tepat kod sumber Netlify asal.
